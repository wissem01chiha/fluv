This list contains resources used as references for implementing fbb components and more mainly learning about flow-based programming.

## Readings

- [Dataflow and Reactive Programming Systems](https://leanpub.com/dataflowbook)
- [J. Paul Morrison — Flow-based Programming](https://www.jpaulmorrison.com/fbp/book.html)
- [Flow-Based Programming, 2nd Edition: A New Approach to Application Development](https://www.amazon.com/Flow-Based-Programming-2nd-Application-Development/dp/1451542321)
- [An Empirical Evaluation of Flow Based Programming in the Machine Learning Deployment Context](https://arxiv.org/pdf/2204.12781)
- [Flow Based Programming - I shouldn't write new languages (talk)](https://www.youtube.com/watch?v=wlna48I2aIE)
- [Dataflow-programming literatures](https://github.com/lingzhi227/dataflow-programming-literatures)
- https://ptolemy.berkeley.edu/papers/03/blockdiagram/edwards2003semantics.pdf
- https://www.researchgate.net/publication/316946830_Simulating_preemptive_scheduling_with_timing-aware_blocks_in_Simulink
- [Giotto: A Time-Triggered Language for Embedded Programming](https://ckirsch.github.io/publications/journals/ProcIEEE03-Giotto.pdf)
- [ARTS: A Real-Time Scheduling Framework for Time-Triggered Systems](https://cs.uni-salzburg.at/~anas/papers/ARTS-chapter.pdf)
- [Real-Time Systems: Scheduling, Analysis, and Verification](https://link.springer.com/book/10.1007/978-3-319-99966-0)
- [Logical Execution Time: A New Paradigm for Real-Time Systems](https://ieeexplore.ieee.org/document/8761234)
- [Rate Transition Blocks Explained](https://ethz.ch/content/dam/ethz/special-interest/mavt/dynamic-systems-n-control/idsc-dam/Lectures/Embedded-Control-Systems/AdditionalMaterial/Miscellaneous/Rate_Transition_Blocks_Explained.pdf)
- [Handling Rate Transitions in Simulink](https://www.mathworks.com/help/simulink/ug/handle-rate-transitions.html)

## Software

- [Simulink®](https://www.mathworks.com/products/simulink.html) — a block-diagram environment for modelling and simulating multidomain systems.
- [Robot Operating System](https://www.ros.org/) — a set of software libraries and tools to build robot applications.
- [Apache NiFi](https://nifi.apache.org/) — a data processing and distribution system.
- [Node-RED](https://nodered.org/) — low-code programming for event-driven applications.
- [Akka](https://doc.akka.io/what-is-akka.html) — toolkit for building concurrent, distributed applications.

## Community

- [DrawFBP](https://github.com/jpaulm/drawfbp) — simple FBP editor created by the FBP inventor.
- [FlowHub](https://flowhub.io/) — web-based interface for NoFlo and generic FBP networks.
- [Slang](https://tryslang.com/) — visual stream language.
- [JavaFBP](https://github.com/jpaulm/javafbp) — Java Implementation of Flow-Based Programming (FBP)
- [NoFlo](https://noflojs.org/) — Flow-Based Programming for JavaScript 
- [JSFBP](https://github.com/jpaulm/jsfbp) — FBP implementation written using JavaScript and node-fibers
- [CppFBP](https://github.com/jpaulm/cppfbp)
- [MicroFlo](http://microflo.org/)
- [Pyperator](https://github.com/baffelli/pyperator) —  Simple python workflow engine based on asyncio and a DAG structure.
- [PaPy](http://mcieslik-mctp.github.io/papy/) — Parallel Pipelines in Python
- [GoFlow](https://github.com/trustmaster/goflow)  — Flow-based and dataflow programming library for Go (golang)
- [Cascades](https://github.com/cascades-fbp/cascades) — Language-agnostic Flow-based Programming (FBP) framework in Go
- [FlowBase](http://github.com/flowbase/flowbase) — A Flow-based Programming inspired micro-framework / un-framework for Go (Golang)
- [Flowgraph](https://github.com/vectaport/flowgraph) — Flowgraph package for scalable asynchronous system development
- [Fractalide](https://github.com/fractalide/fractalide) — Reusable Reproducible Composable Software
