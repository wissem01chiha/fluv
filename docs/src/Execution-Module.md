fbb by default is designed to handle 3 distinct execution patterns.
each component in a flow-based network can have one and only one execution semantic.

- Event-triggered execution
- Data-triggered execution
- Time-triggered execution

>[!NOTE]
> It's not required for all components in a graph to have the same execution pattern; fbb can handle a mixture of execution modes.
